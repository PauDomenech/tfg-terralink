Descripció Detallada

Adaptador per al mòdem 4G Huawei E3372 HiLink.

Patró Adapter.

Gestiona l'enviament i recepció de SMS via l'API REST del Huawei HiLink accessible a http://192.168.8.1/api/. Fa polling periòdic cada 30 segons per detectar SMS entrants nous i els emet via el signal smsRebut.

Protocol intern:

  • Obté token CSRF i sessió de /api/webserver/SesTokInfo
  • Envia SMS via POST a /api/sms/send-sms
  • Llista SMS via POST a /api/sms/sms-list
Mireu també
ServeiSMS, AdaptadorWhatsApp
