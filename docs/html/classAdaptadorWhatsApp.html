Descripció Detallada

Adaptador per a la integració amb WhatsApp via Node.js.

Patró Adapter.

Gestiona el procés Node.js (whatsapp.js) mitjançant QProcess. La comunicació es fa via stdin/stdout:

  • Qt envia comandes: SEND:numero:text, GET_CONTACTS, EMERGENCY
  • Node respon: SEND_OK, SEND_ERROR, APP_READY, APP_DISCONNECTED, QR_ASCII_START/END, CONTACTS_START/END, INCOMING:
