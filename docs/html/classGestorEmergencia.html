Descripció Detallada

Gestiona el protocol d'emergència.

Patró Strategy (broadcast multicanal).

Envia missatges d'emergència simultàniament per tots els canals disponibles (WhatsApp, SMS, LoRa). Emet signals per notificar l'estat de cada enviament a la UI, permetent mostrar feedback visual per canal.
