Descripció Detallada

Widget d'indicador visual (etiqueta + LED) per a un canal de comunicació.

Mostra el nom curt del canal (WA, SMS, LoRa) junt amb un indicador lluminós de color (verd/vermell/gris) que reflecteix la seva disponibilitat actual. Implementa el requisit RF8. Pensat per usar-se com a widget promogut ("Promote to...") des del Qt Designer: el constructor només accepta el parent, i el text es configura després amb setEtiqueta().
