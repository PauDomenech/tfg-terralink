Descripció Detallada

Classe abstracta base per a tots els tipus de missatge.

Conté les dades comunes a tots els missatges (text, data, estat, canal). Les subclasses concretes (MissatgeWhatsApp, MissatgeSMS, MissatgeLoRa) implementen els mètodes virtuals purs.

Mireu també
MissatgeWhatsApp, MissatgeSMS, MissatgeLoRa, MissatgeFactory
