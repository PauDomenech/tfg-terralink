Descripció Detallada

Diàleg per visualitzar i imprimir els missatges rebuts.

Mostra els últims 20 missatges del RepositoriMissatges (WhatsApp, SMS i LoRa) i permet imprimir-ne qualsevol via la impressora tèrmica ESC/POS. El botó "Prova foto" permet verificar la impressió d'imatges.
