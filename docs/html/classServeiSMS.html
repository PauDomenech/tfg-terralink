Descripció Detallada

Implementació del servei de missatgeria via SMS.

Patró Strategy.

Implementa IServeiMissatgeria usant l'AdaptadorModem4G per enviar SMS i rebre'n via l'API REST del Huawei E3372 HiLink (http://192.168.8.1). La recepció es fa per polling cada 30 segons.

Mireu també
IServeiMissatgeria, AdaptadorModem4G, GestorCanals
