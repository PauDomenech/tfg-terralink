Descripció Detallada

Servei de transcripció d'àudio a text mitjançant Whisper.

Executa el script Python transcriure.py via QProcess per transcriure fitxers d'àudio WAV en local, sense connexió a internet. Suporta català, castellà i detecció automàtica d'idioma.
